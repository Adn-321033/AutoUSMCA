# AutoUSMCA

Sistema de Automatización para el Cálculo de Contenido Regional.

## Objetivo

Automatizar el procesamiento de información de costos y consumos para calcular el porcentaje de contenido no regional y validar el cumplimiento de la regla de origen del USMCA/T-MEC.

## Tecnologías

- Python
- Tkinter
- Pandas
- SQLite
- OpenPyXL
- XlsxWriter
- ReportLab
- pytest
